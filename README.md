# resume

Public mirror of Lance Lacoste's résumé PDF.

`resume.pdf` is published automatically from the private source repo
(`llacoste/resume-private`) on every release — do not edit it by hand. The
source (LaTeX, build, history) lives in the private repo; only the compiled
PDF is public here.

The PDF is served at `https://resume.lancelacoste.com/resume.pdf` and embedded
by the résumé page on the main site. The bare subdomain root
(`resume.lancelacoste.com`) redirects to
[lancelacoste.com/resume](https://lancelacoste.com/resume).
